# 📌 PHP Practicals  

## 📂 Practicals List  

### 🏁 **Basic PHP Scripting**  
- `PR1a.php`  : Create a simple PHP script to display "Hello, World!"  
- `PR1b.php`  : Demonstrate the use of variables and data types in PHP  
- `PR1c.php`  : Implement control structures (`if`, `else`)  
- `PR1d.php`  : Use loops (`for`, `while`) to execute a block of code multiple times  

### 📦 **Arrays & Functions**  
- `PR2a.php`  : Create simple and associative arrays in PHP  
- `PR2b.php`  : Manipulate and iterate through arrays using loops  
- `PR2c.php`  : Write user-defined functions and understand scope  

### 🏗️ **Object-Oriented Programming (OOP)**  
- `PR3a.php`  : Create a class with properties and methods in PHP  
- `PR3b.php`  : Implement inheritance in PHP classes  
- `PR3c.php`  : Use polymorphism with method overriding  

### 📝 **Form Handling & Validation**  
- `PR4a.php`  : Develop a web form for user input using HTML and PHP  
- `PR4b.php`  : Validate user input data on the server-side using PHP  

### 🛢️ **Database Interaction (MySQL + PHP)**  
- `PR5a.php`  : Establish a connection to a MySQL database using PHP  
- `PR5b.php`  : Perform basic CRUD operations via PHP  

### 🔑 **User Authentication & Sessions**  
- `PR6a.php`  : Implement session management in PHP  
- `PR6b.php`  : Create user login functionality using sessions  

### 🖥️ **Content Management System (CMS)**  
- `PR7a.php`  : Develop a simple PHP-based content management system (CMS)  
- `PR7b.php`  : Include features such as adding, editing, and deleting posts  

### 📁 **File Handling & Uploads**  
- `PR8a.php`  : Implement file upload functionality in a PHP application  

### 📧 **Email & Web Services**  
- `PR9a.php`  : Use PHP to send emails using the `mail()` function  
- `PR10a.php` : Connect and interact with web services using PHP (e.g., REST APIs)  

### 🍪 **Cookies & User Data Management**  
- `PR11a.php` : Create and manage cookies in PHP  

### 🎨 **Responsive Web Design & Integration**  
- `PR12a.php` : Develop a responsive website layout using PHP integrated with Bootstrap
