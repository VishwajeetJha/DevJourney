# 🛠️ Contributing to DevJourney  

Thank you for considering contributing to **DevJourney**! 🚀 This repository is my personal coding archive, but I welcome feedback and suggestions. Follow the guidelines below to contribute effectively.  

---

## 📌 General Guidelines  
- Be **respectful** and **constructive** in discussions.  
- Ensure your code follows **best practices** and is **well-documented**.  
- Always create a **new branch** for changes—**no direct pushes to `main`**.  

---

## 🏗️ How to Contribute  

### 1️⃣ **Fork the Repository**  
Click the **Fork** button in the top-right corner to create your own copy.  

### 2️⃣ **Clone Your Fork**  
```bash
git clone https://github.com/your-username/DevJourney.git
cd DevJourney
```

### 3️⃣ **Create a New Branch**  
```bash
git checkout -b feature-branch
```
Replace `feature-branch` with a meaningful name (e.g., `fix-readme-typo`).  

### 4️⃣ **Make Changes & Commit**  
- Modify files as needed.  
- Keep commit messages **clear and concise**.  

```bash
git add .
git commit -m "Brief description of changes"
```

### 5️⃣ **Push the Changes**  
```bash
git push origin feature-branch
```

### 6️⃣ **Create a Pull Request (PR)**  
- Go to the original repository on GitHub.  
- Click **Pull Requests** → **New Pull Request**.  
- Select your **feature branch** and compare it with `main`.  
- Provide a **clear title** and **description** of your changes.  
- Submit the PR and wait for review.  

---

## ✅ Pull Request Guidelines  
- Follow the **code style** and **formatting** of the repo.  
- Describe **why** the change was made.  
- Reference any related **issues** (if applicable).  
- Resolve **any requested changes** before merging.  

---

## 🔥 Contribution Do’s & Don’ts  

✔ **Do:**  
- Follow the branch naming convention (`feature-xyz`, `bugfix-xyz`).  
- Keep PRs **small and focused**—one feature/fix per PR.  
- Write **meaningful commit messages**.  

❌ **Don't:**  
- Push directly to `main`.  
- Submit untested or broken code.  
- Leave PR descriptions empty.
