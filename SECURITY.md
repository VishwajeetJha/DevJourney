# Security Policy

## About Versions

For all Semester 5 projects, in Machine Learning and Artificial Intelligence certain Python versions and dependency versions are use.
All of which is mentioned in requirements.txt and pythonverion files.

## Reporting a Vulnerability

If there is any sort of issue regarding versions and their security, or regarding SECURITY itself in any of my code, use the Issues tab (just after Code tab" and post a new issue.
Describe everything in detail using the Bug Report template, don't strictly follow the template, but be sure to include any and everything necessary!
