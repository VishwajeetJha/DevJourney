# 🤖 IoT Practicals List

## 🟢 Basic Arduino Applications
- `IOT03.ino`  : Blink On-board LED at One Second Interval  
- `IOT04.ino`  : Control RGB LEDs with Pushbuttons  
- `IOT05.ino`  : Automated Traffic Signal System using LEDs  
- `IOT06.ino`  : Control LED Brightness with Potentiometer  

## 🌡️ Sensor-Based Applications
- `IOT07.ino`  : Temperature and Humidity Measurement using DHT Sensor  
- `IOT08.ino`  : Distance Measurement using Ultrasonic Sensor  
- `IOT09.ino`  : Motion Detection using PIR Sensor  
- `IOT10.ino`  : Servo Motor Control (0° to 180° Rotation)  
- `IOT11.ino`  : Display "Hello IoT" on 16x2 LCD  

## 🏠 Smart Control
- `IOT12.ino`  : Smart Appliance Control using Relay Module
